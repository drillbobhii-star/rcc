# Cuentas del catálogo estático

El catálogo utiliza Supabase directamente desde el navegador para correo, Google, favoritos y votos. Consulta [Configuración de Supabase](supabase-setup.md) para completar la clave pública del sitio estático.

La dirección oficial de retorno es https://rcc-3m0.pages.dev. Las tablas y las políticas RLS ya existen; no se requiere ejecutar SQL ni configurar Functions. Los comentarios y el contador del backend anterior no se consultan desde el catálogo estático. Los archivos históricos y las migraciones aplicadas se conservaron sin cambios.
